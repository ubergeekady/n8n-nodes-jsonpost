# Project Structure

Your n8n-nodes-jsonpost project should have the following structure:

```
n8n-nodes-jsonpost/
├── nodes/
│   └── JSONPost/
│       ├── JSONPostTrigger.node.ts
│       └── jsonpost.svg (icon file)
├── credentials/
│   └── JSONPostApi.credentials.ts
├── package.json
├── tsconfig.json
├── gulpfile.js (for building icons)
├── README.md
└── .eslintrc.js (optional)
```

## File Descriptions

### nodes/JSONPost/JSONPostTrigger.node.ts

The main trigger node implementation that:

- Defines the node properties and UI
- Implements webhook lifecycle (create, check, delete)
- Handles incoming webhook data
- Loads available endpoints dynamically

### credentials/JSONPostApi.credentials.ts

The credentials definition that:

- Defines the API key input field
- Implements authentication headers
- Provides credential testing functionality

### package.json

Node package configuration with:

- Package metadata
- n8n-specific configuration
- Dependencies and build scripts

### tsconfig.json

TypeScript compiler configuration

### jsonpost.svg

Icon for the node (64x64px recommended). You can create a simple SVG:


## Building the Node

1. **Install dependencies:**

   ```bash
   npm install
   ```

2. **Build the project:**

   ```bash
   npm run build
   ```

3. **Development mode (watch):**
   ```bash
   npm run dev
   ```

## Testing Locally

### Option 1: Link Locally

```bash
# In your node package directory
npm run build
npm link

# In your n8n installation directory
npm link n8n-nodes-jsonpost
```

### Option 2: Test in n8n Docker

Create a `docker-compose.yml`:

```yaml
version: '3.8'
services:
  n8n:
    image: n8nio/n8n
    ports:
      - '5678:5678'
    environment:
      - N8N_COMMUNITY_PACKAGES=n8n-nodes-jsonpost
    volumes:
      - ./n8n_data:/home/node/.n8n
```

## Publishing to npm

1. **Create an npm account** if you don't have one

2. **Login to npm:**

   ```bash
   npm login
   ```

3. **Ensure package.json has correct information:**
   - Update `name`, `version`, `author`, `repository`
   - Ensure `keywords` includes "n8n-community-node-package"

4. **Build and test:**

   ```bash
   npm run build
   npm run lint
   ```

5. **Publish:**
   ```bash
   npm publish --access public
   ```

## Gulpfile.js for Icon Handling

Create a `gulpfile.js` to copy icon files:

```javascript
const gulp = require('gulp');

gulp.task('build:icons', () => {
	return gulp.src('nodes/**/*.{png,svg}').pipe(gulp.dest('dist/nodes'));
});

gulp.task('default', gulp.series('build:icons'));
```

## Important Notes

1. **Node Naming**: The class name must match the file name pattern
   - File: `JSONPostTrigger.node.ts`
   - Class: `JSONPostTrigger`

2. **Credentials Naming**: Must match the name referenced in the node
   - File: `JSONPostApi.credentials.ts`
   - Class name: `JSONPostApi`
   - Referenced as: `'jsonPostApi'`

3. **Webhook Path**: The webhook path is automatically generated by n8n based on your workflow ID

4. **Static Data**: Use `this.getWorkflowStaticData('node')` to persist data between webhook lifecycle events

5. **Error Handling**: Always wrap API calls in try-catch blocks and provide meaningful error messages
